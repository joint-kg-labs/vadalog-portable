Rules

        

          
h(X) :- b(X).
a rule; Y only in the head is existential

          
p(1,"a").
a fact

          
X = Y :- body.
equality-generating dependency

          
#F :- body.
fail when the body matches

          
not p(X)
negation (must be stratified)

          
#f(X,Y)
Skolem function: a deterministic null

          
J = X + 1
assignment when J is not bound in the body

        

      

      

        
Annotations

        

          
@output("p").
emit this relation — + Output writes this for you

          
@input("p").
read it from its binding

          
@bind("p","csv",d,f).
attach a CSV file — + Source writes this for you

          
@mapping("p",0,c,t).
column name and type

          
@post("p","...").
orderby, min, max, argmin, argmax, limit, certain, unique

          
@library(a,l).
math, collections, regex, datatypes, nullManagement, hashCode, monotonic

          
@include("f.vada").
textual inclusion, resolved next to this file

          
${name}
parameter: a constant, or text inside a string, given at run time — ${ } sets the values

        

      

      

        
Aggregates

        

          
msum mprod mcount munion
monotonic: safe inside recursion, one fact per activation

          
min max count sum prod avg
stratified: one fact per group
